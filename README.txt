ГОТОВИЙ ПРОЄКТ PR4 (JAVA + MAVEN)

1. Розпакуй ZIP у зручне місце (наприклад, на Робочий стіл).
2. В IntelliJ IDEA: File -> Open -> вибери папку PR4 (в якій є pom.xml).
3. Натисни Trust Project, якщо буде запит.
4. У Maven натисни Reload All Maven Projects. Потрібен інтернет для завантаження Lombok та JavaFaker.
5. Використовуй JDK 17 або 21.
6. Запусти order.threads/src/main/java/com/example/orders/app/Main.java.
   За потреби увімкни Settings -> Build, Execution, Deployment -> Compiler -> Annotation Processors -> Enable annotation processing.

У проєкті є 3 Java-модулі: order.processing, order.storage, order.threads.
Головний клас: com.example.orders.app.Main.
Твій старий проєкт PR4 можна не змінювати: нову папку відкривай в окремому вікні.
